`garden-melody.wav` is an original 32-second instrumental loop generated by
`scripts/generate-audio.py`. It contains no third-party recording or composition.
It is included for unrestricted use with this project.

Replace it with your own licensed MP3, OGG, or WAV, then change `music.src` in
`src/config/wedding.ts`. Paths are relative to `public/` (no leading slash),
so deployments in GitHub Pages subdirectories also work.
